AAQ PHYSICS WORKING PILOT 0.1.0 - 15 October 2026

The working browser interface is now implemented. index.html is the GitHub Pages entry point. There is no build step for the website. See GITHUB-UPLOAD.txt in the downloaded pilot package for publishing instructions.

The bank remains at 28 draft questions: 14 recall and 14 application. Normal sessions use 20 available marks where attainable, with the closest 50/50 question-count balance. Teacher single-question reviews do not affect learner scores. W12 and W27 are automatic answer completions; W25 is the only written self-assessment test.

The UI baseline is the newer chemistry v1.4.2 package. All physics preferences, sessions and progress use separate AAQ storage keys. Question content is unchanged from the content pack.

Core tests, simulated-DOM interface tests and self-contained preview checks passed. Browser-rendered and physical-phone visual QA remain to be performed. The DEVELOPMENT folder in the download contains reproducible tests and a preview builder; it does not need publishing.
