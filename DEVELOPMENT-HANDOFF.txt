QUESTION RENDERER CONTRACT
- Show the full command-word prompt, context and any table. Give diagrams meaningful accessible descriptions and an enlarge/close action that restores focus.
- Use fieldsets/legends or equally clear labels for each choice part. Stable option IDs are authoritative; displayed letters are temporary. Persist shuffled option order and selected IDs in an active attempt.
- For answer-completion questions, show the supplied opening followed by clearly labelled sentence gaps. Selecting a sentence fills that gap. All options remain available until the whole question is checked. The opening earns no marks. After checking, show the completed model paragraph and part-specific correction/feedback.
- Numeric boxes show the authored unit or an allowed-unit selector. Preserve raw student values plus normalised values. Finite decimals, common grouped thousands and scientific notation are accepted. Do not evaluate arbitrary expressions. Inline syntax help must not erase an entry.
- Check the whole question once, including all calculation boxes. If parts are empty, state which are empty and offer return-to-answer or intentional submission. Feedback must not leak later answers while those parts remain unsubmitted.
- ECF marks require the rule on that numeric part; do not award them generally. Show the original error and label the later credit as 'Method mark awarded (error carried forward)'. A correct downstream value is direct credit. Display direct and ECF totals separately.
- Four calculation questions provide a separately selected final-answer mode in the data (W03, W09, W11, W24). A correct final value in an allowed unit earns full practice credit in that explicit mode. A wrong value can return to scaffolding before submission; do not silently claim a method or award partial working. W07 has two independent calculations and retains its scaffold.
- W25 is the only open response. Use a labelled text area; preserve the first submitted answer before revealing its four bullet marking points. Place an integer self-score box (0-4) at the end of that question's marking workflow. Empty is not zero. Preserve the writing on validation failure. Never claim automatic prose grading.

SESSION CONTRACT
- The target is 20 AVAILABLE marks, not 20 marks earned. Start with studied leaf lessons; eligibility requires ALL required lessons. Do not silently select a prerequisite or include future content.
- Resolve a whole-question subset to exactly 20 where possible. Among equally sized mark totals, choose the closest to 50% recall by QUESTION COUNT. Prefer less-seen questions as a tie-break. The reference module uses a seeded shuffle and dynamic programming.
- Keep question IDs unique. At most one question from each family: W12 and W25 are variants and never appear together. Do not duplicate an item or split its marks to fill a session.
- If 20 cannot be reached, use the greatest attainable total below 20 and show it before starting. If zero questions are eligible, explain missing lessons instead of starting. A shortened session or balance deviation is explicit; never add untaught material to fix it.
- Keep session composition fixed on resume, including question IDs, content versions, mark total, seed, option orders and first attempts. A question's required lessons cannot change the active session silently.
- Keep question position for navigation; show completed available marks out of planned available marks as workload progress. Show marks earned separately. Submitted blank parts still belong to a submitted question; unfinished questions do not count as completed.

PROGRESS RECORD CONTRACT
Use namespaced keys such as aaqPhysics.prefs.v1, aaqPhysics.progress.v1 and aaqPhysics.active.v1. Version the saved envelope and bank. Do not clear unrelated storage.
An attempt records: questionId, contentVersion, requiredLessonIds, strand, interaction, startedAt/submittedAt, raw responses, option orders, marking mode, part statuses, directMarks, ecfMarks, selfAssessedMarks (null until entered), maxMarks, hintUsed, revealed and attemptNumber.
Keep the first submission immutable; retain later retries as later events. A model-answer reveal is not a correct attempt. Preserve both the written answer and its self-reported score. Treat incomplete/corrupt storage as recoverable; show a useful message and avoid overwriting recoverable data with an empty object.
At session end, show direct + ECF automatic marks and self-assessed marks as distinct values with their respective denominators. Mark a self-assessment awaiting a score as pending. Do not silently combine self-reported scores with automatically verified performance.

REVIEW AND RELEASE
Every question is currently draft-for-teacher-review. The core defaults to excluding drafts; pass allowDrafts:true only for an explicitly labelled teacher preview. A student release uses teacher-approved questions. Review status is content approval, not an automatically checked fact.
The earlier 24-question workbook/PDF remains the planning record. For pilot implementation use this bank: W12 has become a four-gap automated completion, W25 is the only written self-assessment, and W26-W28 extend the examples. All question and part identifiers are stable within this pack; the supplied bankVersion/contentVersion distinguish this iteration.

FRONTEND ACCEPTANCE CHECKS
1. Preserve layout at narrow phone, tablet and desktop widths; no sideways page scrolling. Enlarge diagrams rather than shrinking labels.
2. Verify keyboard-only answer selection, focus after Check/Next/Close, accessible group labels and announced marking status. Convey ECF through text, not colour alone.
3. Keep the mobile bar and virtual keyboard from hiding numeric fields, the written score field or Continue. Preserve minimum comfortable tap targets and reduced-motion preferences.
4. Resume an incomplete calculation, a filled but unchecked completion, a marked question and a written answer awaiting a self-score without loss or reordering.
5. Compare displayed question totals, workload progress and scores with the reference results, including partial submissions, reveal, shorter pools and dependent marks.
6. Confirm selection and grading still work when permitted browser storage is unavailable. Provide an honest persistence message.
7. Review with the teacher, then a small group of students. Record confusing distractors, time per mark, abandoned questions and the usefulness of the ECF explanation before expanding the bank.
