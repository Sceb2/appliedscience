AAQ PHYSICS PILOT v0.1.2 — 15 October 2026

GitHub Pages entry point: index.html. No build step or external runtime dependencies. See GITHUB-UPLOAD.txt in the ZIP for teacher instructions.

Version 0.1.2 installs five elaborate question celebrations and a larger perfect-session finale. effects.js provides setPreferences, clear, question, session and preview. A five-item shuffled bag prevents consecutive repeats. Canvas 2D renders confetti, streamers and trails; SVG/CSS provide centrepieces and fallbacks. The canvas resolution is capped at device-pixel ratio 2. A single animation frame loop and finite cleanup timer belong to each active effect. Navigation, hidden pages, page exit, resize and changes to reduced-motion preferences cancel motion. CSS also hides effects under prefers-reduced-motion. Sound is opt-in for the session finale only.

Teacher question review now includes an effect selector and Play celebration, without recording learner attempts. Actual question celebrations retain the full-mark, no-hint, non-teacher-review condition. Questions worth 3+ marks now use the same five-item rotation; every effect contains confetti.

The report module/config and bottom-of-question draft workflow from v0.1.1 are retained. No reporting recipient has been supplied. No progress schema, storage key, marking rule, question-bank or lesson-map changes were made.

The DEVELOPMENT tests use Happy DOM and instrumented canvas commands. They test functionality rather than rendered appearance. Rebuild OPEN-PILOT.html with python DEVELOPMENT/build_preview.py from the package root after any runtime edits.
